# Dark/Light Mode Toggle - Quick Start

## 🌓 How to Use

### Toggle Theme Button

Located in the top-right corner of the header

- **Click** to switch between dark and light modes
- **Sun icon** (☀️) = Light mode is available
- **Moon icon** (🌙) = Dark mode is available

### Theme Automatically Saves

Your theme preference is remembered:

- Next time you visit, your chosen theme loads automatically
- Stored in browser's local storage
- Synced across tabs/windows (same browser)

---

## 🎨 Visual Guide

### Dark Mode (Default)

```
Header: Dark background with light text
Cards: Gray boxes with light text
Buttons: Gray with light hover states
Icons: Bright/visible colors
```

### Light Mode

```
Header: Light background with dark text
Cards: White boxes with dark text
Buttons: Light gray with darker hover
Icons: Dark/muted colors
```

---

## ⌨️ Keyboard Shortcuts

**No keyboard shortcuts yet**, but you can:

1. **Tab** to the theme toggle button in the header
2. **Space** or **Enter** to activate

---

## 🔄 Auto-Detection

First time using PII Guard?

- If your system is set to dark mode, dark mode loads automatically
- If your system is set to light mode, light mode loads automatically
- You can always override by clicking the toggle button

---

## 💾 Data Persistence

### What Gets Saved?

- Your theme preference (dark/light)
- Nothing else (no personal data)

### Where is it Saved?

- Browser local storage
- **Not** sent to servers
- **Not** collected or tracked

### How Long Does it Last?

- Until you clear browser data
- If you clear "Cookies and cached images", theme preference is deleted

---

## 🐛 Troubleshooting

### Theme not changing?

✅ Try clicking the toggle button again  
✅ Refresh the page (F5)  
✅ Check if JavaScript is enabled

### Theme resets after refresh?

✅ Check browser privacy settings
✅ Enable localStorage (usually enabled by default)
✅ Not using private/incognito mode (localStorage disabled there)

### Colors look wrong?

✅ Clear browser cache (Ctrl+Shift+Delete)  
✅ Try different browser zoom level  
✅ Check if browser is zoomed in/out

## 🎯 Tips & Best Practices

✅ **Use Dark Mode for:** Long sessions, eye strain reduction, battery saving (OLED screens)

✅ **Use Light Mode for:** Bright environments, printing documents, accessibility needs

✅ **Keyboard Users:** Tab to theme button, press Space or Enter to toggle

✅ **Accessibility:** Both modes meet WCAG AA contrast requirements
